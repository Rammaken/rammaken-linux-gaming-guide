# Overview
Roblox is officially unsupported in Linux through regular executions like WINE/Proton so the community created an alternative.

# Guide
1. Install `flatpak` (If Arch user, open your terminal and run `sudo pacman -S flatpak`).
2. Install Sober (If Arch, run `flatpak install flathub org.vinegarhq.Sober` to install Sober).
3. Go to Roblox webpage and launch any experience from it.
4. Sober will guide you further on the initial settings of it. Should work fine.
