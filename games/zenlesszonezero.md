# Overview
Zenless Zone Zero runs out of the box with DW-Proton on Steam.

# Guide
1. Install `DWProton` (If Arch user, open terminal and run `yay -S dwproton-bin`)
2. Open properties menu on your ZZZ and force compatibility with `dwproton`
